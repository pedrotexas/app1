# Smart Líder IA · Desafio 7 dias (app PWA)

App web instalável (celular e computador) do Desafio Smart Líder IA.

- `index.html`: telas e estilos
- `app.js`: conteúdo dos 7 dias, diagnóstico, progresso, cartão de resultado e modo equipe
- `sw.js` + `manifest.webmanifest`: instalação e uso offline
- Modo equipe: funções `sl_*` no Supabase (projeto Jornada)
